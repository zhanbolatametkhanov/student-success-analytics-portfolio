Risk analysis

Queries can identify repeated absence, missed assessments, declining performance and changes in engagement.

SELECT student_id,
       COUNT(*) AS absences
FROM attendance
WHERE status = 'ABSENT'
GROUP BY student_id
HAVING COUNT(*) >= 3;
