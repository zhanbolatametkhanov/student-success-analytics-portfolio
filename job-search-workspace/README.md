# Personal Job-Search Workspace

A local-first Streamlit app for continuous job discovery, résumé-based matching, editable application drafts, and application tracking.

Inspired by the workflow goals of [GodsScion/Auto_job_applier_linkedIn](https://github.com/GodsScion/Auto_job_applier_linkedIn), this is a separate app. It does not run the upstream bot or automate LinkedIn.

## Continuous job monitoring

- The **Continuous monitor** tab starts a background scanner. It scans immediately, then every six hours while the Codespace stays running.
- The default source is the [Arbeitnow public Job Board API](https://www.arbeitnow.com/blog/job-board-api). It is a public API intended for job-board use. The scanner checks a bounded number of pages, filters relevant Austria-location and remote roles, deduplicates by URL, and adds new jobs to local SQLite.
- Arbeitnow provides a European jobs feed weighted toward Germany, not an exhaustive Austrian feed. To improve Austria coverage, the monitor also supports the **Adzuna Austria API** using your own API credentials.
- To configure Adzuna, create an account at [Adzuna Developer](https://developer.adzuna.com/) and create an application. Inside `job-search-workspace`, create a private `.env` file containing these two lines (replace the example values locally; do not paste your API keys into chat or commit them):

```text
ADZUNA_APP_ID=your_app_id
ADZUNA_APP_KEY=your_app_key
```

The file is covered by `.gitignore`. Restart the monitor after changing the file. When the credentials are present, it searches Austria for full-time data analyst, data engineer, business systems analyst, systems engineer and IT manager roles, including Vienna-focused searches.

- Use **Run one scan now** to test sources, or run `python monitor.py --once` in the terminal.
- To monitor from the terminal, run `python monitor.py --interval-hours 6`; stop with `Ctrl+C`.
- The monitor runs only while the Codespace/container remains running. Codespaces can sleep or stop, so use an always-on machine or authorised scheduled service for dependable round-the-clock checks.
- Newly discovered jobs are saved to SQLite. Each new job receives an editable cover-letter and screening-interest draft based on the saved profile and matched terms. Refresh the dashboard to see them.
- Remote listings still need checking to confirm which countries the employer allows.

## Automatic application submission limitation

This version **does not submit applications automatically**. It continuously searches the supported APIs, saves matches, uses your saved résumé text, creates editable drafts, and can package those drafts with your stored résumé PDF. It cannot submit to every employer site.

Job sites use different application forms and eligibility declarations, and there is no universal applicant-side submission API. Greenhouse's documented submission endpoint requires an employer API key; Lever's application API key is generated by a Lever Super Admin. A job seeker generally does not have those employer credentials. Do not use credentials you are not authorised to use.

The app will not automate LinkedIn, scrape AMS alle jobs, evade CAPTCHA or access controls, guess work-authorisation/sponsorship answers, or accept legal declarations on your behalf. AMS alle jobs is for manual search and prohibits automated extraction. Use the employer's official page to review and submit the application unless an employer provides an applicant-authorised automation route.

## Privacy defaults

- No external AI API calls. Drafts use local templates and résumé-derived keywords.
- Jobs/drafts are stored in `data/jobs.sqlite3`; the candidate profile is stored in `profile.json`; the original uploaded CV is stored in `data/private_resume.pdf`.
- These personal files, monitor logs, API credentials in `.env`, and scan state are excluded from Git. The public repository contains only a generic profile template.
- In Codespaces, your résumé and profile are stored in that cloud-hosted workspace, even though they are not sent to an AI provider. For processing physically confined to your own computer, run locally.

## Run in GitHub Codespaces (Bash)

Open a Codespace on the `add-personal-job-search-workspace` branch, then run these commands one at a time:

```bash
cd /workspaces/student-success-analytics-portfolio/job-search-workspace
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address 0.0.0.0
```

Open port 8501 when Codespaces offers it. Keep the terminal running; stop the app with `Ctrl+C`. Keep the forwarded port private.

## First-use workflow

1. Open **Profile & data** and upload the résumé PDF. Click **Extract résumé text and save to private profile**; the app stores the PDF and extracted text in ignored files.
2. Confirm the candidate profile and target skills. Text extraction does not OCR scanned/image-only PDFs.
3. Optional but recommended: configure Adzuna API credentials in `.env` for country-specific Austrian searches.
4. Open **Continuous monitor** and click **Start continuous monitor**. It scans immediately and then every six hours while running.
5. Review results under **Match jobs**. Fit weights are skills (45%), role fit (25%), location (20%), and full-time status (10%); this is a prioritisation aid, not a hiring prediction.
6. Newly found roles receive editable draft letters. Use **Drafts** to review and download an application review pack ZIP that can include the saved PDF.
7. Verify employer-specific details, qualifications, work eligibility, declarations and privacy notices, then submit on the official employer page yourself. Update the tracker afterward.

## CSV format

The built-in CSV template is available in **Add / import jobs**. Required columns: `title`, `company`. Optional columns include `location`, `job_url`, `description`, `requirements`, `employment_type`, `work_arrangement`, `source`, and `posted_date`.

## Fit score transparency

Scores compare terms in job titles, descriptions, and requirements with terms in the saved candidate profile, including a limited list of terms found in the résumé text. A high score does not verify work authorisation, salary, seniority, sponsorship, language requirements, or employer interest. Confirm those details manually.

## Files

- `app.py` — dashboard, SQLite tracker, local PDF extraction, scoring, draft and review-pack interface
- `monitor.py` — six-hour scanner using Arbeitnow and optional Adzuna Austria API
- `profile.example.json` — generic starting profile
- `profile.json` — private candidate profile and extracted résumé text; never commit
- `data/private_resume.pdf` — uploaded résumé; never commit
- `data/jobs.sqlite3` — local tracker database; never commit
