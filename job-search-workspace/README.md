# Personal Job-Search Workspace

A local-first Streamlit app for continuously monitoring a permitted public job API, filtering Austria/Vienna and relevant remote roles, matching jobs against résumé-derived terms, preparing editable application drafts, and tracking applications.

Inspired by the workflow goals of [GodsScion/Auto_job_applier_linkedIn](https://github.com/GodsScion/Auto_job_applier_linkedIn), this is a separate application. It does not run the upstream bot or automate LinkedIn.

## Current automation

- The **Continuous monitor** tab can start a background scanner. It scans immediately and then every six hours while this Codespace stays running.
- The scanner uses the [Arbeitnow public Job Board API](https://www.arbeitnow.com/blog/job-board-api), a public API intended for job-board use. It scans a bounded number of pages, filters for Austria-location and relevant remote roles, then saves new matches to the local SQLite tracker. It links back to the provider and observes a low polling frequency.
- The source API is European and currently weighted toward Germany, so it is not a complete Austrian vacancy feed. Remote listings must be checked for the countries an employer actually permits.
- You can also run one scan using the **Run one scan now** button, or from the terminal with `python monitor.py --once`.
- To monitor from the terminal, run `python monitor.py --interval-hours 6`. Stop it with `Ctrl+C`.
- The monitor runs only while the Codespace/container remains running. Codespaces can stop or sleep; for dependable round-the-clock checks, run the scanner on an always-on machine or an authorised scheduled service.
- New matching listings are added to the database automatically; open or refresh the dashboard to see them.

## Application submission limitation

This version **does not submit applications automatically**. It discovers and ranks jobs, prepares application packs, and retains your résumé locally. Job sites use different application forms and eligibility declarations, and there is no universal applicant-side submission API. For example, Greenhouse's documented submission endpoint requires an employer API key, and Lever's documented submission API key is generated by a Lever Super Admin. Do not attempt to use employer credentials you do not have.

The app won't automate LinkedIn, scrape AMS alle jobs, evade CAPTCHA or access controls, guess work authorisation/sponsorship answers, or accept legal declarations on your behalf. AMS alle jobs is for manual searching and prohibits automated extraction. Use official employer pages to review and submit each application unless an employer provides an applicant-authorised automation route.

## Safety and privacy defaults

- No LinkedIn scraping, browser automation, login automation, third-party form filling, or automatic application submission.
- No external AI calls. Drafts use local templates and terms extracted from the résumé PDF you upload.
- Jobs/drafts are stored in `data/jobs.sqlite3`; the local candidate profile is stored in `profile.json`; the uploaded PDF is stored in `data/private_resume.pdf`.
- Those personal files, monitor logs, and scan state are excluded from Git. The public repository contains only a generic profile template.
- When run in Codespaces, your PDF and profile are stored in the cloud-hosted workspace (not sent to an AI API). For processing that remains physically on your own computer, run locally.

## Run in GitHub Codespaces (Bash)

Open a Codespace on the `add-personal-job-search-workspace` branch, then run these commands one at a time:

```bash
cd /workspaces/student-success-analytics-portfolio/job-search-workspace
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address 0.0.0.0
```

When Codespaces offers to open port 8501, open it in the browser. Keep the terminal running; stop the app with `Ctrl+C`. Keep the forwarded port private.

## First-use workflow

1. Open **Profile & data** and upload your résumé PDF. Click **Extract résumé text and save to private profile**. The app stores both the extracted text and the original PDF inside ignored local files.
2. Check the candidate profile and correct any terms. Text extraction does not run OCR on scanned/image-only PDFs.
3. Open **Continuous monitor** and click **Start continuous monitor**. It scans once right away, then every six hours while running.
4. Open **Match jobs** to review results and gaps. The weighted score uses skills (45%), role fit (25%), location (20%), and full-time status (10%). It is a prioritisation aid, not a prediction of hiring success.
5. Generate and edit cover-letter and screening-interest drafts. The **Drafts** tab lets you download an application review pack ZIP with the stored PDF, job details, drafts, and a checklist.
6. Open the employer's official application page, check every fact and declaration, then submit manually. Update the tracker afterward.

## Austria search launchpad

The **Austria search** tab opens official Austrian search pages and suggests phrases. Search these pages manually and add suitable listings to the tracker:

- [AMS alle jobs](https://jobs.ams.at/public/emps/)
- [AMS eJob-Room](https://jobroom.ams.or.at/)
- [Jobbörse der Republik Österreich](https://bund.jobboerse.gv.at/sap/bc/jobs/)

## CSV format

The built-in CSV template is available in **Add / import jobs**. Required columns are `title` and `company`. Optional columns include `location`, `job_url`, `description`, `requirements`, `employment_type`, `work_arrangement`, `source`, and `posted_date`.

## Fit score transparency

Scores compare terms in the job title/description/requirements with terms in the candidate profile, including a limited vocabulary found in the saved résumé text. A high score does not verify work authorisation, salary, seniority, sponsorship, language requirements, or employer interest. Confirm those details manually.

## Files

- `app.py` — dashboard, SQLite tracking, score logic, local PDF extraction, Austria search links, monitor controls and application pack export
- `monitor.py` — bounded public API scanner and six-hour polling loop
- `profile.example.json` — generic Austria-first starting profile
- `profile.json` — local candidate profile and extracted résumé text; intentionally not committed
- `data/private_resume.pdf` — uploaded CV; intentionally not committed
- `data/jobs.sqlite3` — job tracker; intentionally not committed
